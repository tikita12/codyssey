# 노코드 자동화 미션 제출물

## 0. 개요
- 프로젝트 한 줄 소개
  구글폼으로 모임 참석자를 받고, 참석확인 메일을 보내는 것
- 사용한 도구 목록 : Make, Zapier

---

## 프로젝트 1. 자동화 도구 비교 구현

### 1-1. 공통 워크플로우 정의
- 자동화할 워크플로우 설명
 폼 제출→ 라우터로 참석/불참 판단→ [참석이면] 시트에 기록하고 → 확인 메일 발송
                                                → [불참이면] 시트에 기록 (필요시 불참 메일)

- Trigger (시작 이벤트) 
  폼 제출이 시작되면 트리거가 작동을 합니다.

- Action (처리 동작)
  action1,2 : 참석과 불참을 구분해서 각각 구글시트에 저장
  action3 : 참석자에게 확인 메일 발송

- 조건 분기 (Filter/Router) 
  폼의 참석여부를 확인해서 참석/불참을 나누는 분기가 있습니다.

### 1-2. Make 구현
- 도구 이름 : Make

- 워크플로우 구성 요약
  Trigger : 폼제출
  분기-참석 Action1 : google sheet 참석자리스트 저장-Action3 : 참석확인메일 발송
        -불참 Action2 : google sheet 불참자리스트 저장

### 1-3. Zaiper 구현
- 도구 이름 : Zaiper

- 워크플로우 구성 요약 (Trigger / Action / 분기)
 Trigger : 폼제출-Filter1 : 참석-Action1 : google sheet 참석자리스트 저장-action3 : 참석확인메일 발송
 Trigger : 폼제출-Filter1 : 불참-Action2 : google sheet 불참자리스트 저장

### 1-5. 비교 분석 보고서
- 구현 과정 요약
  Zaiper는 매핑이 비교적 쉬워서 과제가 빨리 끝난 반면에 Make의 경우 처음 쓰는 사람에게 매핑하는 방법이 너무 불친절하여 오류를 많이 발생시켰다. 매핑시킬 때 계속 경로를 열어서 value값을 설정하는 방법을 몰라 고생하거나, 매핑을 시켰는데도 값이 이상한 곳에 고정되어 같은 값만 나오기도 하였다. 
다만 Zaiper의 경우 분기를 나눌 수 있는 filter와 path기능이 유료여서 중간에 zaiper의 설계를 아예 바꿀 수 밖에 없었다.

- 비교 항목 표 (5개 이상)

  | 비교 항목 | Make | Zaiper |
  |-----------|--------|--------|
  | 설정난이도   |    1    |    4    |
  | 연동서비스   |    2   |    4    |
  | 로그확인방식   |    4  |    5   |
  | 무료플랜   |    5    |    1    |
  | UI/UX   |    5   |    4   |

- Make 장단점
  장점 : 무료 router를 쓸 수 있는 것이 가장 큰 장점이고, UI가 알아보기 편하다
  단점 : value값 설정이 처음 make를 사용하는 사람에게 큰 장벽으로 다가온다

- Zaiper
  장점 : 값 mapping이 쉽게 되어있고, 로그 또한 보기 편하게 되어있다
  단점 : 무료로 쓸 수 있는 기능이 한정적이다.

- 어떤 상황에서 어떤 도구가 적합한지 의견
  분기 없이 필터만 걸어서 하나의 작업을 하는 경우, 예를 들어 점수가 80점 이상인 사람에게 합격메일을 보낸다 같은 경우는 Zaiper가 좋을 것같고, Make의 경우 router를 통해 두가지 이상의 경로를 필요로 하는 경우 Make를 사용하는 것이 적합하다.
다만, Zaiper도 Zap을 두개 만들어서 필터를 여러가지로 걸 수 있으므로 프로젝트 파일이 번거로워질 뿐이지 쓰지 못하는 것은 아니다.

## 프로젝트 2. 자유 주제 자동화 설계 및 구현

### 2-1. 반복 업무 정의
- 자동화할 반복 업무 1개
 평가자알림을 매번 메일을 열어 확인하기가 번거로워 디스코드 알림으로 받고, 아침마다 오는 뉴스레터를 gemini와 연결하여 3줄로 연결하여 구글시트에 저장하는 업무

### 2-2. 도구 선정
- 선정한 도구 이름 : make
- 선정 이유 : 무료 플랜이 넉넉하고, 복잡한 설계도 무료로 가능하고, 라우터나 필터기능도 무료로 사용할 수 있어서 선택하였습니다.
